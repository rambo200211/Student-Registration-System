# Student Registration System

A full-stack web application built for student management using Spring Boot, Thymeleaf, and an H2 database[cite: 1]. 

## Tech Stack
- **Backend:** Spring Boot (Spring MVC, Spring Data JPA, Spring Validation)
- **Database:** H2 Database (In-memory SQL database)
- **Frontend:** HTML5, CSS3, Thymeleaf Template Engine
- **Build Tool:** Maven

## Features
- **Create:** Register new students with validation rules (Name, Email, Phone, Course, Age)[cite: 1, 8, 9].
- **Read:** View all registered students in a dynamic table[cite: 1, 2, 15].
- **Update:** Edit and update existing student details[cite: 1, 2, 12, 16].
- **Delete:** Remove student records from the system[cite: 1, 2, 13, 15].
- **H2 Console:** Inspect and run SQL queries on the database via `/h2-console`[cite: 1, 6, 19].
